# Tareas pendientes

Estas funciones no forman parte de la primera versión local. Para ofrecerlas de
forma segura y sincronizada entre distintos usuarios y dispositivos hace falta
definir e integrar un backend, cuentas de usuario y permisos.

- [ ] Crear cuentas de clientes y un sistema para canjear códigos o enlaces de
  acceso gratuito, con validación y caducidad gestionadas por el servidor.
- [ ] Compartir perfiles infantiles con otros cuidadores y controlar qué puede
  consultar o modificar cada persona.
- [ ] Sincronizar perfiles y registros entre dispositivos y recuperar los datos
  al cambiar de dispositivo.
- [ ] Añadir un chat opcional entre administración y cliente para solicitar
  información específica, incluyendo controles de privacidad y consentimiento.

Los perfiles, los registros por fecha, el cuestionario, la captura de tiempo con
temporizador o entrada manual y los resultados locales corresponden a la fase
actual.
